UNLOYAL FRONT - how to get the .exe (no folders, no coding tools)

1. Extract this zip (right click -> Extract All). Do NOT drag from inside the zip preview.
2. github.com -> New repository (any name) -> click "uploading an existing file".
3. Click "choose your files", open the extracted folder, press Ctrl+A, Open.
   (16 files, no folders.) Click "Commit changes".
4. Back on the repo page: Add file -> Create new file.
   In the name box type:   .github/workflows/build.yml
   (typing the / makes the folders for you)
   Open PASTE-ME-build.yml.txt, copy ALL of it, paste into the big box. Click "Commit changes".
5. Click the "Actions" tab. Wait ~3 min for the green check.
   Click the run -> scroll to "Artifacts" -> download UnloyalFront.
6. Unzip it, run UnloyalFront.exe. (Windows "unknown publisher": More info -> Run anyway.)
